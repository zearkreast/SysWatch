- **Daha hafif ayarlar penceresi:** Sayfalar ilk açıldıklarında kuruluyor. Pencere eskisinin yarısından kısa sürede açılıyor ve açıkken daha az bellek kullanıyor.

## English

- **Lighter settings window:** pages are built the first time they are opened. The window opens in less than half the time it used to and uses less memory while open.
- **Smoother interface:** the window no longer freezes while sensors are read. Unchanged values are not redrawn, and a minimised window stops refreshing.
- **Fix:** typing in the Details search box no longer triggers the "unsaved changes" warning.
- **Diagnostics:** a slow right-click popup now writes its timing to the log.
