İlk sürüm.

- **Uyarılar:** CPU ve GPU sıcaklığı, CPU, GPU ve RAM kullanımı, disk sıcaklığı için düzenlenebilir eşikler; süre, hatırlatma aralığı ve "normale döndü" payıyla.
- **Bildirim kanalları:** Windows bildirimi, Telegram, Discord (webhook ya da bot), e-posta (isteğe bağlı PGP/MIME şifreleme) ve uçtan uca şifreli Signal.
- **Uzaktan komutlar:** Telegram, Discord ve Signal'den `/status`, `/top`, `/kill`, `/shutdown`, `/set`, `/thresholds`, `/mute`; isteğe bağlı PIN ve hatalı denemede kilit.
- **Gizlilik:** Az bilgi modu, DPAPI ile şifreli saklanan tokenlar, telemetri yok.
- **Arayüz:** Frutiger Aero cam tasarım, açık ve koyu tema, canlı grafikler, tüm sensörleri gösteren Detaylar sayfası, son 7 günün geçmişi, tepside sayılar, "Hareketleri azalt".
- **Hafiflik:** Boşta yaklaşık 15 MB bellek; GPU, disk ve RAM doğrudan Windows'tan okunur.
- **Dağıtım:** Kurulum dosyası (eksikse .NET 8'i kendisi kurar, isterseniz Windows açılınca başlatır) ve taşınabilir sürüm.

## English

First release.

- **Alerts:** editable thresholds for CPU and GPU temperature, CPU, GPU and RAM usage and disk temperature, with duration, reminder interval and hysteresis.
- **Channels:** Windows notifications, Telegram, Discord (webhook or bot), e-mail (optional PGP/MIME encryption) and end-to-end encrypted Signal.
- **Remote commands:** `/status`, `/top`, `/kill`, `/shutdown`, `/set`, `/thresholds`, `/mute` from Telegram, Discord and Signal, with an optional PIN and lockout.
- **Privacy:** minimal-info mode, secrets encrypted with DPAPI, no telemetry.
- **Interface:** Frutiger Aero glass design, light and dark themes, live charts, a details page with every sensor, 7-day history, tray numbers, reduced motion.
- **Lightweight:** about 15 MB of memory at idle; GPU, disk and RAM are read straight from Windows.
- **Distribution:** an installer (installs .NET 8 when missing, optional start with Windows) and a portable build.
